---
name: script-style-top-list
description: Writing rules for top-N list videos (Top 5 / Top 10) about a trending topic.
---
- Countdown from N to 1, best item last; tease #1 in the hook.
- Each item = 1–2 scenes: `on_screen_text` with the number and name, `broll`/`ai_image` visual, one surprising fact.
- Keep items balanced in length; Shorts: max 5 items.
- Every item needs its own proof (a fact, number or real image), not just a name; vary the visual type between consecutive items.
- Give the countdown a mini-cliffhanger between items ("but number 2 changes everything").
- Long videos: each item (or pair of items) is one `block`, titled with its number and name (the chapters let viewers jump); the mini-cliffhanger is the block's `continuity` line.
